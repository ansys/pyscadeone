Operator instance#

An OperatorInstanceApplication object is an Expression object representing an operator instance call, the called operator being represented by an instance of the top-level class OperatorInstance

A block can refer to an operator instance or an operator expression.

Note: array-related operations are described in the Array section.

Higher-order operator instance#

Higher-order operations (operations using an operator as parameter) are represented by instances of the OperatorExpression class.

Table 9 Higher-order operators#

Higher-order

Application

map, fold, mapfold, mapi foldi, mapfoldi

array iterators

activate operator expression every

conditional activation

restart operator expression every

conditional restart
